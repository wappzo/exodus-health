How to install

Gmail

Settings → See all settings → General → Signature → Create new → paste with Cmd/Ctrl+V

Outlook (Web)

Settings → Mail → Compose and reply → Email signature → paste with Cmd/Ctrl+V

Apple Mail

Mail → Settings → Signatures → create blank → paste. Then set as default for your account.

Outlook (Desktop)

File → Options → Mail → Signatures → New → paste into the rich-text editor.
